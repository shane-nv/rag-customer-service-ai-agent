# Return & Exchange Policy Overview

MiraLoom offers a 14-day return and exchange window starting from the delivery (sign-off) date so you can shop with confidence. Eligible items can be returned for a refund or exchanged for a different style, size, or color.
For domestic orders we arrange doorstep pickup; for cross-border orders, please ship the item back to the return address provided by our support team. Return shipping for non-defective items is paid by the buyer; for defective, damaged, or mis-shipped items, MiraLoom covers the full shipping cost.
Some items are non-returnable for hygiene or customization reasons — see "Return & Exchange Eligibility." All requests must be submitted within the window via the Member Center or customer support; late requests cannot be accepted.
